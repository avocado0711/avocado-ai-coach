# 知识来源与审核约定

当前仓库中的 `strength_training.txt` 是产品内部整理稿，不应被描述为医学指南、
同行评议研究或权威机构原文。正式公开使用前必须完成以下工作：

机器可读的审核状态、文件哈希和版本记录在 `knowledge_registry.json`。只有
`review_status` 为 `approved` 且填写了 `reviewer`、`reviewed_at` 的来源，才会被
生产环境启动检查接受。修改来源文件后必须同步更新 SHA-256，否则审计会失败。
项目作者以专业教练身份自审时，应使用 `scripts/review_source.py` 记录审核人、时间和
当前文件哈希，审核完成后重新构建知识库。

1. 为每个知识片段记录来源名称、链接或 ISBN、发布日期、适用人群和证据等级。
2. 将动作教学、训练计划、营养建议和伤病康复分别审核，不使用单一通用文本
   覆盖所有场景。
3. 伤病内容必须由医生或注册康复师审核，并明确诊断、治疗和训练建议的边界。
4. 对“必须”“100%”“根治”等绝对化表述进行清理。
5. 每次内容更新保留版本号、审核人和更新时间。
6. 回答中只展示能够追溯到片段的来源，不生成伪引用。

建议优先建立的来源清单：

- 世界卫生组织身体活动指南。
- 美国运动医学会（ACSM）运动测试与处方指南。
- 美国国家体能协会（NSCA）力量训练相关教材。
- 中国体育科学学会或国内正规体育院校发布的训练指南。
- 针对具体伤病的临床实践指南，由专业人员判断是否适用于产品场景。

在完成审核前，产品文案不得宣称“专业康复处方”“医疗级判断”或“保证改善”。
