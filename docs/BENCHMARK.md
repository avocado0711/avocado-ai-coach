## 解释边界

- 46 条相关性样本规模很小，95% 置信区间仍然较宽，不能包装成大规模用户验证。
- 相近 query 已从指标中排除，但训练数据与知识文档仍可能存在语义关联。
- 该结果只说明当前链路在开发集上满足回归预期；上线前仍需独立人工标注和真实试点。
- CPU 上 P95 约 2.6 秒仅包含检索与重排，不包含大模型首字延迟。
